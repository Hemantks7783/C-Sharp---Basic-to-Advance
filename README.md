## 💻 Practice Programs (Lesson 20)

To consolidate your learning from Lessons 1–19, complete the following practice challenges found in the `/Module-01/Practice` directory:

1. **Calculator App:** Simple console application supporting basic arithmetic with `switch` expressions.
2. **Number Guessing Game:** Practice loops, conditionals, and random number generation.
3. **Student Grade Tracker:** Work with `List<T>`, arrays, and methods to calculate dynamic averages.
